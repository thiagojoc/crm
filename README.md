# CRM FlowSales

CRM de prospecção da FlowSales, arquivo único (`index.html`), sem build,
publicado em [thiagojoc.github.io/crm](https://thiagojoc.github.io/crm).

Antes vivia em `thiagojoc/flowsales-crm/crmflowsalessjc.html`; agora fica
sozinho aqui, com todas as funções originais preservadas (mesmo projeto
Firebase/Firestore compartilhado com as outras ferramentas do Thiago).

## Publicar (GitHub Pages)

Se a página `thiagojoc.github.io/crm` ainda não estiver no ar, ative o
GitHub Pages deste repositório: **Settings → Pages → Build and
deployment → Source: Deploy from a branch → Branch: main, pasta / (root)
→ Save**. Depois de alguns minutos o site fica disponível no endereço
acima.
